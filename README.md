# LAB5 · T2 Giáo dục · L3A · Bàn 5

Trợ lý học bài trên trang khoá học "Nhập môn phân tích dữ liệu": khi AI sai hoặc không chắc thì học viên thấy gì, và AI được tự làm tới đâu.

- [`spec.md`](spec.md): bài nộp, bảng thành viên ở đầu
- [`prototype/index.html`](prototype/index.html): prototype bấm được (mở bằng trình duyệt), ảnh đánh số `prototype/screen-*.png`
- [`prototype/phan_loai.py`](prototype/phan_loai.py): lời gọi OpenAI thật cho quyết định chính, log ở `prototype/log-phan-loai.json`
- [`GLOSSARY.md`](GLOSSARY.md): thuật ngữ dùng thống nhất

Dữ liệu trong bài là dữ liệu dựng của track. Không có API key trong repo.
